# Journal Abbreviation Formatter - スタンドアロン版

## 概要
Python環境がないPCでも使用できるスタンドアロン版のJournal Abbreviation Formatterです。

## ファイル説明
- `JournalAbbreviationFormatter.exe` - 実行可能ファイル（約52MB）
- 全ての必要な依存関係が含まれているため、Python環境は不要です

## 使用方法

### 1. 起動
`JournalAbbreviationFormatter.exe` をダブルクリックして起動します。

### 2. 基本的な使い方
1. **RISデータ入力**: 上部のテキストエリアにRIS形式の参考文献データを入力または貼り付け
2. **フォーマット実行**: 「🔄 フォーマット実行」ボタンをクリック
3. **結果確認**: 下部のテキストエリアにフォーマット済みの参考文献が表示
4. **コピー**: 「📋 結果をコピー」ボタンで結果をクリップボードにコピー

### 3. 便利な機能

#### クリップボード機能
- **自動コピー**: 設定で有効にすると、フォーマット実行時に自動でクリップボードにコピー
- **貼り付けボタン**: 「📋 クリップボードから貼り付け」で簡単にデータ入力
- **手動コピー**: 「📋 結果をコピー」で結果を手動コピー

#### 設定機能
- **フォント設定**: 「⚙️ 設定」から各テキストエリアのフォントとサイズを変更可能
- **クリップボード設定**: 自動コピー機能のON/OFF切り替え

#### Early Access論文対応
- Early Access論文の場合、年月を選択するダイアログが表示
- 適切な年月を選択することで正確なフォーマットが可能

### 4. サポートされる形式
- **入力**: RIS形式（Reference Information Systems）
- **出力**: 学術論文で使用される標準的な参考文献形式

### 5. システム要件
- Windows 7 以降
- メモリ: 最小 2GB RAM
- ディスク容量: 約 100MB の空き容量

### 6. トラブルシューティング

#### 起動しない場合
- Windows Defenderやアンチウイルスソフトが実行をブロックしている可能性
- 管理者権限で実行を試してください

#### 文字化けする場合
- 設定画面でフォントを「Meiryo」や「MS Gothic」に変更してください

#### データが正しくフォーマットされない場合
- 入力データがRIS形式であることを確認してください
- TY（文献タイプ）が正しく設定されていることを確認してください

### 7. データファイルについて
アプリケーションには以下のデータが内蔵されています：
- `jo_abb.csv`: 雑誌略語データ
- `jo_del.csv`: 削除する単語リスト
- `mo_abb.csv`: 月略語データ
- `settings.yml`: 設定ファイル

文献情報フォーマッター（ブラウザ版）

Tkinter版のロジックをHTML+JSに移植。del.csv と replace.csv を読み込み、TeX/Plainを選んで整形します。 変換結果は自動でクリップボードへコピーされます。

ショートカット: Ctrl/⌘+Enter で変換
🧹

例: word
🔁
replace.csv（置換辞書 / 2列: 元, 置換後 / 先頭行ヘッダ可）
例: International, Int.

CSV 仕様と注意点
  • del.csv: 1列のCSV。先頭行はヘッダでもOK。各行のワードが一致したら削除します。
  • replace.csv: 2列のCSV（元, 置換後）。先頭行はヘッダでもOK。完全一致で置換し、末尾にピリオドを補います。
  • ワードの一致はカンマ除去後（"," を抜いた単語）で照合します。
  • TeX モードでは pp. a-b → pp. a--b、末尾ピリオド付与、ジャーナル部を \\textit{...} で包み、最初のカンマ前で } を挿入する元実装の挙動を再現します。
  • 入力フォーマットは 著者名, "タイトル" ジャーナル情報 を想定。
